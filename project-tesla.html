The project

Racking for an automated warehouse served by stacker cranes

Our crew installed the racking of an automated high-bay warehouse for Tesla in Lelystad, in the Netherlands. Stacker cranes run between the racks on a floor rail, so every frame has to be set out, plumbed and aligned with precision along each aisle.

We worked for Noega Systems, the system provider, in 2022, and installed around 3,000 tonnes of steel with lifting platforms inside the building.
